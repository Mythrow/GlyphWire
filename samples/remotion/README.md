# Cyclone sample (Remotion)

15-second, 1080x1920, 30 fps vertical scene in `src/CycloneShort.tsx`.

## Setup
```bash
cd samples/remotion
npm install
```

## Preview
```bash
npx remotion studio src/index.ts
```

## Render
```bash
npm run render
```
Output: `out/cyclone_remotion.mp4` (git-ignored).

Pinned: remotion 4.0.290, react 18.3.1, TypeScript 5.6.3. Node 22 was used.
